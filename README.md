# ジェスチャーパーティー 🙆

みんなのスマホで遊べるジェスチャーゲームのWebアプリです。

- 部屋のURLを送るだけで参加（ログイン不要・最大10人）
- 個人戦 / チーム戦（あか・あお）
- 答え方：入力（自動判定）/ 声（演じる人が正解ボタン）/ 両方
- タイムアタック：「時間内に何問？」と「何問を何秒で？」
- お題は8ジャンル・約230語を内蔵

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | ページ本体 |
| `style.css` | 見た目 |
| `app.js` | ゲームのしくみ |
| `words.js` | お題（ここを書きかえるとお題を増やせます） |
| `firebase-config.js` | Firebaseの設定を貼るところ |

## セットアップ

### 1. Firebaseプロジェクトをつくる
1. https://console.firebase.google.com/ で「プロジェクトを追加」（名前の例：`gesture-game`、Googleアナリティクスはオフで大丈夫）
2. 左メニュー「構築」→「Realtime Database」→「データベースを作成」
   - 場所：**シンガポール（asia-southeast1）** が日本から近いです
   - 「ロックモードで開始」を選ぶ
3. 「ルール」タブを開き、下のルールに書きかえて「公開」

```json
{
  "rules": {
    ".read": false,
    ".write": false,
    "rooms": {
      "$roomId": {
        ".read": true,
        ".write": true,
        ".validate": "$roomId.length <= 8"
      }
    }
  }
}
```

> 部屋のコードを知っている人だけがその部屋を読み書きできます。部屋の一覧は誰も見られません。

### 2. Webアプリを登録して設定をコピー
1. 歯車アイコン「プロジェクトの設定」→「マイアプリ」→ `</>`（ウェブ）を押して登録
2. 表示された `firebaseConfig` の中身を、`firebase-config.js` の `""` の中にそれぞれ貼る
3. **`databaseURL` が必ず入っているか確認**（なければ Realtime Database の画面上部にある `https://〜.firebasedatabase.app` を貼る）

### 3. GitHubで公開
1. リポジトリ `GESTURE-GAME` をつくり、5つのファイルをアップロード
2. 「Settings」→「Pages」→ Branch を `main` / `(root)` にして保存
3. 数分後に `https://ユーザー名.github.io/GESTURE-GAME/` で遊べます

## デモモード
`firebase-config.js` が空のままだと、**同じブラウザの別タブ同士**だけで動くデモモードになります。設定前の動作確認に使えます。

## お題を増やすには
`words.js` を開いて、ジャンルの `words` に `'言葉|よみ|別の言い方'` の形で追加します。

- カタカナ・ひらがなは自動で同じあつかい（`'ゴリラ'` だけで「ごりら」も正解）
- 漢字の言葉は読みも入れる（`'野球|やきゅう'`）
- 1つ目に書いた言葉がお題として表示されます

## 古い部屋の掃除（任意）
遊び終わった部屋はデータベースに残ります。たまった場合は Firebase コンソールの Realtime Database で `rooms` を削除してください。
